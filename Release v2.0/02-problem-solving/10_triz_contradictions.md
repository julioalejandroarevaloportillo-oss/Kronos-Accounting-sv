# 🔍 SKILL 10: TRIZ Contradiction Matrix & Inventive Principles

## 🎯 Purpose
Overcome apparent irreconcilable dilemmas (e.g. "Increase audit thoroughness without slowing down transaction processing throughput").

## 🛠️ Execution Protocol
1. **Define the Engineering Contradiction:**
   - Improving Parameter $X$ (e.g., Audit Rigor / Verification Depth).
   - Worsening Parameter $Y$ (e.g., User Latency / System Response Time).
2. **Apply TRIZ Inventions:**
   - *Segmentation:* Split verification into async background audits + sync fast checks.
   - *Preliminary Action:* Pre-validate vendor NRCs and digital certificates in cache.
   - *Inversion:* Let vendors self-validate invoices via a sandbox before submission.
3. **Formulate the Win-Win Architecture:** Discard compromise solutions that degrade quality.
