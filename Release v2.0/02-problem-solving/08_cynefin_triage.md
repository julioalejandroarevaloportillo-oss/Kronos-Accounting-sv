# 🔍 SKILL 08: Cynefin Framework & Incident Triage

## 🎯 Purpose
Determine the correct cognitive strategy for any problem domain, avoiding over-engineering simple tasks or applying rigid playbooks to chaotic events.

## 🛠️ Execution Protocol
1. **Classify the Operational Domain:**
   - **Clear (Best Practice):** Known causes, known solutions $\rightarrow$ *Sense - Categorize - Respond* (Apply SOP).
   - **Complicated (Good Practice):** Multiple valid solutions, requires expert analysis $\rightarrow$ *Sense - Analyze - Respond* (Evaluate options).
   - **Complex (Emergent Practice):** Unpredictable non-linear dynamics $\rightarrow$ *Probe - Sense - Respond* (Run safe-to-fail experiments).
   - **Chaotic (Novel Practice):** Active disaster, security breach, server outage $\rightarrow$ *Act - Sense - Respond* (Contain hemorrhage immediately).
2. **Execute Containment / Resolution Protocol:** Switch communication frequency and response speed to match domain.
