# 🔍 SKILL 07: First-Principles Reasoning & Assumption Inversion

## 🎯 Purpose
Solve problems where conventional industry practices are slow, expensive, or inefficient by stripping legacy baggage and rebuilding from physical and mathematical constants.

## 🛠️ Execution Protocol
1. **Identify the Core Premise:** State what "everyone believes" must be done (e.g. "We need 5 accountants to manually key in invoices").
2. **Interrogate Underlying Assumptions:**
   - Is it legally mandated? (Check tax code text vs. popular myth).
   - Is it technically constrained? (Compute byte size, token throughput, API rate limits).
3. **Isolate Indisputable Ground Truths:**
   - Invoices are cryptographic JSON strings signed by government keys.
   - Mathematics is deterministic.
4. **Re-synthesize Optimal Path:** Construct the solution from ground truths with minimal moving parts.
