# 📈 SKILL 24: Power BI Executive Dashboard UX & Visual Design

## 🎯 Purpose
Design high-impact, decluttered executive dashboards that surface answers in 5 seconds, avoiding visual chartjunk and saturated rainbow colors.

## 🛠️ Execution Protocol
1. **The 5-Second Rule & Visual Hierarchy:**
   - **Top Row:** 4 to 5 KPI Cards (Revenue, Operating Margin, Cash Flow, Pending Invoices) with micro-trend sparklines.
   - **Middle Tier:** Primary analytical visual (e.g. Monthly Revenue vs. Prior Year Bar Chart).
   - **Bottom Tier:** Drill-through transactional table or detailed breakdown matrix.
2. **Color Palette Standards:**
   - Neutral Gray background (`#F4F6F9`) with white visual containers.
   - Primary Accent: Corporate Navy Blue (`#0F2C59`).
   - Positive Indicator: Forest Green (`#1E824C`), never neon green.
   - Negative Alert: Crimson Red (`#C0392B`), reserved exclusively for bad variances or critical alerts.
3. **Chart Selection Invariants:**
   - Never use 3D charts or pie charts with $>4$ slices.
   - Use horizontal bar charts for categorical rankings with long text labels.
