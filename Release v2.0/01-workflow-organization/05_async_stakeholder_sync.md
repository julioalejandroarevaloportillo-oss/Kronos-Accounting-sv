# 📋 SKILL 05: Asynchronous Stakeholder Sync & Status Generator

## 🎯 Purpose
Deliver zero-fluff, actionable asynchronous progress reports tailored for engineering leads, CFOs, or operational directors.

## 🛠️ Execution Protocol
1. **The 3P Format (Progress, Plans, Problems):**
   - **Progress (Last Period):** Shipped items with measurable outcomes (e.g. "Validated 1,420 DTEs, 0 errors").
   - **Plans (Next Period):** Next 3 high-impact deliverables committed.
   - **Problems (Blockers):** Exact point of friction, owner, and requested action.
2. **Context Tailoring:** Strip implementation details when addressing executives; highlight cash flow, risks, and milestones.
3. **Action Items Matrix:** State `[WHO] does [WHAT] by [EXACT TIMESTAMP]`.
