# 🛡️ SKILL 13: Anti-Slop: Active Voice & Anti-Hedging Assertiveness

## 🎯 Purpose
Convert weak, passive, apologetic writing into crisp, actionable, high-accountability language.

## 🛠️ Execution Protocol
1. **Purge Hedging & Timid Modals:**
   - ❌ *"It might be possible that we could perhaps consider running the reconciliation..."*
   - ✅ *"Run the bank reconciliation across accounts 1101 and 1102."*
   - ❌ *"I apologize for any confusion this might have caused..."*
   - ✅ State the corrected fact directly.
2. **Enforce Subject-Verb-Object Active Voice:**
   - ❌ *"The invoices were parsed by the script."*
   - ✅ *"The script parsed 450 invoices."*
3. **Accountability Assignment:** Every recommendation must specify the actor and the concrete action.
